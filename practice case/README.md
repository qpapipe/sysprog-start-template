# Заказ 06 — наблюдатель за папкой
Напишите свой обработчик, который следит за `inbox/` и передаёт поступившие файлы
в `processed/`. Нельзя начинать обработку файла, пока он ещё копируется.
Повторный запуск после падения не должен дублировать ранее успешно обработанные файлы.

В отдельном терминале запустите `python simulate_arrivals.py slow` — симулятор
добавит файл частями с задержкой. Дополнительные режимы `duplicate`, `broken`, `burst`.

Не удаляйте `source/`; входящую `inbox/` можно очищать между тестами.
В сдаче покажите журнал, отметки уже обработанных файлов и результат повтора.
